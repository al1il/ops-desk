CH 01

SRT Monitor

+

Match monitoring, Slack alerts, operational reports, and self-diagnostics on Google Sheets + Apps Script.

Problem
Operators needed continuous visibility into scheduled matches, assignment state, and decoder health without opening dozens of sheets or missing Slack noise.
Solution
A modular Apps Script suite (19 deployable files) that cycles monitors, surfaces log viewers, helpdesk UI, decoder finder, and independent permissioned menus. Formula-owned columns stay untouched; secrets stay server-side.
Tech
Google Apps Script V8 · Google Sheets · HtmlService single-file UIs · Slack · static pre-deploy checks
Impact
One coherent operational surface for monitoring, alerting, and reporting. Versioned bundles, rollback tags, and runbooks so the system can be handed over safely.
CH 02

Match Timing

+

Control center for timestamp comparison, divergence analysis, SLA checks, and executive slide decks.

Problem
QS log timestamps and final approved timestamps drift. Finding which matches, by how much, and whether SLA is at risk required manual spreadsheets and tribal knowledge.
Solution
A menu-driven control center with modeless UI: analysis engine, merge workflow, health checks, scoped filters (date, country, competition, shift), and both legacy multi-slide reports and focused gap reports. Optional Slack Block Kit delivery.
Tech
Google Apps Script · Sheets · Slides · HtmlService · time-driven triggers
Impact
Operators can run analysis + report in one place, investigate missing data, and keep a run history.
CH 03

Ops Report Builder

+

Daily operational report from acquisition data → PDF + Slack, single-file Apps Script.

Problem
Daily ops reporting was manual assembly: pull data, shape narrative, export PDF, post to Slack. Fragile under volume and shift changes.
Solution
One standalone Apps Script file that snapshots master data (fast path + fallback), rebuilds Ops and Carry-Over views, writes report text, generates PDF, and posts the link. Menu for manual runs and settings. Optional Wyscout relay.
Tech
Google Apps Script · Sheets · PDF generation · Slack · time-based triggers
Impact
Repeatable daily deliverable with a clear log of stages. Source stays copy-paste deployable—no bundler.
CH 04

Match Sync + Forecast

+

Bookmarklet → Sheets sync, SLA classification, analysis dashboard, and independent forecast studio.

Problem
Match records lived on external pages. Getting them into the operational sheet, classifying SLA timing, and projecting future load required repeated copy-paste and guesswork.
Solution
Browser bookmarklet collects eligible records (timezone-aware), posts to an Apps Script endpoint with batch acknowledgement, rebuilds analysis, and surfaces a dashboard plus a separate Forecast Studio based on historical site/league patterns.
Tech
Bookmarklet · Apps Script web app · Sheets · HtmlService dashboard · PDF export
Impact
Idempotent sync path and operator-tested baseline. Forecasts are estimates, not guarantees.
CH 05

Personal Command

+

Private low-cost command center for projects, tasks, notes, and daily briefing — Cloudflare Worker + D1.

Problem
Personal project tracking, decisions, and daily notes were scattered. Needed a private, cheap, always-on surface that stays under operator control.
Solution
Authenticated Worker (HMAC session) + D1. Projects, tasks, documents, decisions, maintenance, roadmap, daily briefing, focus timer, exports. No third-party script CDNs. Optional read-only GitHub App browsing.
Tech
Cloudflare Workers · D1 · vanilla JS modules · HMAC cookies · system fonts
Impact
Single private desk for personal ops. Zero-build deploy, explicit safety gates, and a design language that prioritizes legibility over decoration.
